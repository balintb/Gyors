Pipe one result into the next.

The input box is a shell. Compose stages with |. Tab completes the next stage. The output of one provider becomes the input of the next.

clip | jq .name | upper | copy

Goodies

·Native, not Electron

Built in Rust. Renders before your finger leaves the spacebar.

·One list, no modes

Apps, files, calc, clipboard, AI, web searches, notes. All ranked together. Just type.

·Clipboard, searchable

clip pulls up your past copies, filtered as you type. URLs open. JSON pretty-prints. Hex colors swatch. Numbers convert. Timestamps decode. Emails compose.

·AI as a result

Local Ollama by default. OpenAI / Anthropic with your own key. Summarize, explain, translate, rewrite, or just ai why does my Mac do this.

·Calculator with units

5 kg to lbs. 3h 20m in s. 2^10. 15% of 89. 0xff → binary. Inline.

·Notes + scratchpad

Markdown notes, edited and saved without leaving the panel. Plus scratch, a one-keystroke jot drawer that's always there.

·Snippetsbeta

Type ;sig; anywhere and your signature lands. ;date; → today. Defined once, expanded system-wide.

·History & recall

Up-arrow walks past queries. !! re-runs the last one. Frecency boosts what you actually use to the top.

·Find any file

Add ' and Spotlight kicks in. Your most-touched files float up first.

·Shell passthrough

>ls -la runs in your login shell. Aliases and functions work.

·System actions

Window management. Screenshots. Kill processes by name. Deep-link System Settings. Empty Trash. Lock screen. All keyboard.

·Repo-aware

repo riff finds your local checkout, opens it in VS Code, jumps to GitHub, lists pull requests, runs git status inline.

·Plugins

JSON one-liners or process binaries. Validated and sandboxed. gyors plugin scaffold mything → you're shipping.

·Themeable

Pick from the menu bar. Install community themes by clicking a gyors://theme?import=… link.
